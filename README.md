# Коми-налка

Игра: 10 квартир в Инте (Республика Коми), угадай цену продажи. Данные — объявления Авито.
Статический сайт: один файл `index.html` (данные внутри), без сборки.

## Баллы
За квартиру: `1000 × (1 − |ln(ваша / реальная)| / ln 3)`, минимум 0. Максимум за игру — 10 000.
Ошибка в 2 раза (в любую сторону) — около 370 баллов, в 3 раза и больше — 0.
Тип игрока: среднее значение ln(ваша / реальная); ниже −0,10 — «Жадный студент», выше +0,10 — «Транжира», иначе — «Адекватный квартирант».
Бегунок логарифмический (50 тыс. — 2 млн ₽), чтобы дешёвые квартиры можно было оценить точно.
